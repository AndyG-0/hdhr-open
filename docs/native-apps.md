# Native Apps (Android / iOS / tvOS)

!!! note "Not published yet"
    The Android, iOS, and tvOS apps are **not available on the Google Play
    Store or Apple App Store**. The source for all three lives in this
    repository and works great, but today the only way to run them is to
    build from source yourself.

- **Android**: [`android/`](https://github.com/AndyG-0/hdhr-open/tree/main/android) —
  see [`android/README.md`](https://github.com/AndyG-0/hdhr-open/blob/main/android/README.md)
  for building in Android Studio and installing a release build (sideloaded
  APK; no expiry once signed).
- **iOS / iPadOS**: [`apple/`](https://github.com/AndyG-0/hdhr-open/tree/main/apple) —
  see [`apple/README.md`](https://github.com/AndyG-0/hdhr-open/blob/main/apple/README.md#sideloading)
  for building in Xcode and sideloading with a free Apple ID (7-day expiry,
  rebuild weekly).
- **Apple TV (tvOS)**: same `apple/` project as iOS — same README, same
  sideloading steps, same free-tier limitation.

In the meantime, the [web app](usage.md) works fine in a mobile or Apple TV
browser.
