# Linux barebones (non-Docker) deployment

This directory holds the scripts (`install.sh`, `update.sh`, `uninstall.sh`)
and systemd unit templates (`hdhr-open-backend.service`,
`hdhr-open-frontend.service`) for running HDHR Open directly on a host
without Docker.

For the full walkthrough — one-line install, manual setup, hardware
acceleration, updating, and uninstalling — see the hosted docs:

- [Installation](https://andyg-0.github.io/hdhr-open/installation/#barebones-no-docker)
- [Hardware Acceleration](https://andyg-0.github.io/hdhr-open/hardware-acceleration/)
- [Updating & Uninstalling](https://andyg-0.github.io/hdhr-open/updating/)
